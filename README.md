# Adb & Fastboot GUI

Простой и удобный графический интерфейс (GUI) для работы с инструментами ADB (Android Debug Bridge) и Fastboot. Больше не нужно вводить сложные команды в терминале — управляйте вашим Android-устройством в один клик.

## 🚀 Основные возможности

* **Поиск устройств:** быстрое обнаружение подключенных девайсов в режимах ADB и Fastboot.
* **Перезагрузка:** переключение в режимы Recovery, Bootloader (Fastboot) и System.
* **Управление файлами:** удобная загрузка (push) и скачивание (pull) файлов.
* **Установка приложений:** инсталляция APK-файлов простым выбором пути.
* **Прошивка (Fastboot):** прошивка разделов (boot, recovery, system) через графическое меню.
* **Логирование:** просмотр логов работы утилиты в реальном времени.

## 🛠 Системные требования

* Операционная система: Windows 10/11
* Установленные драйверы ADB и Fastboot

## 📦 Установка и запуск

1. Скачайте архив из раздела [Releases]
2. Распакуйте в удобное место.
3. Запустите исполняемый файл приложения.

# Adb & Fastboot GUI

A simple and user-friendly graphical interface (GUI) for working with ADB (Android Debug Bridge) and Fastboot. No more typing complex commands in the terminal—control your Android device with one click.

## 🚀 Key Features

* **Device Search:** Quickly detect connected devices in ADB and Fastboot modes.
* **Reboot:** Switch to Recovery, Bootloader (Fastboot), and System modes.
* **File Management:** Easily push and pull files.
* **App Installation:** Install APK files by simply selecting the path.
* **Flashing (Fastboot):** Flash partitions (boot, recovery, system) via the graphical menu.
* **Logging:** View utility logs in real time.

## 🛠 System Requirements

* Operating System: Windows 10/11
* ADB and Fastboot drivers installed

## 📦 Installation and Launch

1. Download the archive from the [Releases] section
2. Unzip it to a convenient location.
3. Run the application executable file.
